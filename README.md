# Customer Support CRM

Customer Support Ticket Management CRM built for the Datastraw Technologies assessment.

## Stack
- Python
- FastAPI
- SQLModel
- SQLite
- HTML, CSS and JavaScript

## Run locally

```bash
python -m pip install -r requirements.txt
python -m uvicorn main:app --reload
```

Open http://127.0.0.1:8000/

## Core features
- Create support tickets
- List tickets
- Search tickets
- Filter by status
- View ticket details
- Update ticket status
- Add internal notes
